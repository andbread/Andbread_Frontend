## Conventional Commit

- feat
- fix
- refactor
- test
- docs
- chore
- cicd
- build
- style

---

## 제목 형식

```
type: 요약
```

- type은 위 아홉 개 중에서 고릅니다. 새로 만들지 않습니다.
- 콜론 다음에 공백을 하나 둡니다.
- 요약은 한국어로 씁니다.
- 요약은 명사로 끝냅니다.
- 마침표를 붙이지 않습니다.

---

## 명사 종결

서술어를 명사로 바꿔 끝냅니다. `추가`, `수정`, `복원`, `제거`, `분리`, `이관`, `통합`, `적용`, `도입`처럼 한자어 명사를 먼저 찾습니다. 맞는 명사가 없으면 `되돌림`, `올림`처럼 `~ㅁ` 형태로 씁니다.

제목이 `다`로 끝나면 규칙 위반입니다. `~한다`, `~했다`, `~된다`, `~합니다`, `~했습니다`가 모두 여기에 해당합니다.

---

## 좋은 예

```
feat: 랜딩페이지에 FAQ 섹션 추가
fix: 회원 삭제 트리거 연결 복원
refactor: 1인당 정산 금액 계산 로직 추출 및 동작 통일
chore: Vitest 단위 테스트 환경 도입
cicd: E2E 테스트 GitHub Actions 워크플로 추가
test: 정산 금액, 납부일 키, 알림 경로 단위 테스트 추가
```

## 나쁜 예

아래는 실제로 이 레포지토리에 올라간 커밋입니다.

| 나쁜 예 | 문제 | 고친 예 |
| --- | --- | --- |
| `test: E2E 재시도를 측정 결과에 따라 CI 1회로 정한다` | `정한다`로 끝남 | `test: E2E 재시도를 CI에서 1회로 조정` |
| `chore: E2E 실패율 측정용 임시 설정을 되돌린다` | `되돌린다`로 끝남 | `chore: E2E 실패율 측정용 임시 설정 되돌림` |
| `cicd: 워크플로 표시 이름을 Unit Test, E2E Test 로 정리` | 콤마와 공백이 섞여 제목이 길어짐 | `cicd: 워크플로 표시 이름 정리` |
| `chore: 검증 게이트 확인용 타입 오류 추가 (되돌릴 예정)` | `게이트`는 gate의 직역 | `chore: 검증 워크플로 확인용 타입 오류 추가 (되돌릴 예정)` |

---

## 어휘

요약에 쓰는 단어는 `gh-tone` 스킬의 금지 표현 표를 따릅니다. `게이트`, `안전망`, `붙임`, `덮음` 같은 영어 직역을 쓰지 않습니다.
